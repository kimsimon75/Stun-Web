이는 Reforged raw action 0x7a(파서 정규화 ID 0x7b)의 능력 사용 기록이다. 능력 목록의 이름은 모두 T특성강화다. 일반 명령의 orderId도 함께 검색했다. 선택위습제조처럼 설명에 특성 포인트가 있는 다른 명령은 특강 건수에서 제외했다.

동기화 문자열과 게임 캐시 동기화 액션도 검사했다. 게임 캐시 동기화는 두 파일 모두 0건이다. 문자열 동기화는 로그인·저장 데이터 로드·UI·조합·항법 선택·저장 알림이며, 특포 잔액 또는 차감 결과를 나타내는 기록은 발견하지 못했다. 시작 시 CODE_LADD 숫자 payload를 현재 잔액으로 해석하지 않았다.

## 맵 코드 대조와 한계

읽을 수 있는 2.322 fix03_2의 JASS는 특포를 PLAYER_STATE_RESOURCE_FOOD_USED에 저장한다. 특강 처리에서 4 미만이면 반환하고, 성공 경로에서 4를 차감한다. 그러나 이 코드를 2.323의 동일 동작에 대한 완전한 증명으로 사용하지 않았다. 2.323의 JASS는 현재 추출하지 못했으며, 2.323 능력 이름과 설명은 해당 버전 오브젝트 데이터로 대조했다.

결론: 검사한 파일에서는 특강 명령을 직접 읽을 수 있지만, 전후 특포 잔액이나 성공 결과를 직접 읽는 경로는 확인하지 못했다. 재생 화면에 값이 보인다는 사실만으로 파일에 잔액 스냅샷이 있다는 결론을 내릴 수 없다. 반대로 이 검사만으로 모든 버전·모든 기록 방식에 대해 불가능하다고 단정하지 않는다.

현재 파서가 생략하는 필드와 문서화되지 않은 데이터가 있으므로 완전한 형식 해독은 아니다. 특강 클릭만으로 성공을 확정하는 로직은 추가하지 않았다. 4포인트 차감 방식은 잔액을 관측하는 별도 경로 또는 게임 상태 재현이 확보되어야 구현할 수 있다.

재현 도구와 상세 결과는 로컬 `.map-analysis/audit-points.cjs`, `.map-analysis/point-audit.json`에 저장했다. 개인 리플레이 원본과 동기화 payload는 이 문서에 포함하지 않았다.
