# 유닛 원시코드 대조표

기준: ORDR_S2_2.322_fix03_2.w3x의 war3map.w3u, war3map.wts 및 war3map.j.

`rawcode`는 대소문자를 구분하는 기본 유닛 코드입니다. 스킨·변신 전체 코드 목록은 아닙니다. `rawcodeRequiresState`는 코드만으로 계산기 항목을 결정할 수 없다는 뜻입니다. 특강·약주·스킬 레벨이나 중복 계산 항목을 별도로 확인해야 합니다. 이 메타데이터 추가만으로 리플레이 관측 수를 현재 보유 수로 자동 적용하지 않습니다.

맵과 계산기의 등급 차이(코알라, K, 나루토, 엘리자베스)는 표에 그대로 기록했습니다. 계산 수치와 등급은 변경하지 않았습니다. null은 미확정이며 추측으로 배정하지 않았습니다. 아이템·연구소·항법은 유닛 코드 대상에서 제외했습니다.
