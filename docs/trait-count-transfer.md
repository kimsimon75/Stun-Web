# 특강 수량 전환

웹과 Netlify 함수를 함께 배포하고 `dist/StunReplayLink-traits.exe`를 기존 `.env`와 같은 폴더에서 사용합니다. 게임 실행 중 읽기를 중지하는 기존 제한은 유지됩니다. 현재 EXE의 맵 지원은 2.323이며 2.314 리플레이는 지원하지 않습니다.

웹 유닛 연동에서 플레이어를 선택하면 수신한 전환 기록을 한 번 적용합니다. 전체 선택에서는 계산기를 변경하지 않습니다. 기본 수량은 개체당 1 감소(최소 0), 강화 수량은 1 증가합니다. 나머지 기본 개체는 유지하며, 일반 관측 유닛 전체를 현재 보유량으로 적용하지 않습니다.

지원: 상디 H09H → H09G (화면 이름 상디(강화)), 센고쿠 h04E → h0BM, 마르코 h08O → h09Q. 핸콕·크로커다일 등 같은 코드로 능력 레벨만 바뀌는 특강은 자동 전환하지 않습니다.

판정은 특강 명령 주체의 기본 코드, 같은 명령 플레이어가 15초 이내 처음 관측한 강화 개체 하나, 이후 원본의 재관측 부재를 결합합니다. 15초는 관측 연결을 위한 보수적 시간창이며 게임의 확정 규칙이 아닙니다. 후보가 여러 개면 전환하지 않습니다. 포인트 잔액/소유권을 직접 읽은 확정 판정은 아니므로 다른 개체의 선택이 섞이면 오판 가능성이 있고, 늦게 선택하면 누락될 수 있습니다.

기본 개체 이력은 전송 원본에 검증용으로 보존하되 서버 관측 합계에서 제외합니다. 페이지를 열어 둔 동안 같은 전환은 재수신해도 중복 적용되지 않습니다. 페이지를 새로 열면 수신 기록을 다시 적용합니다. 수동 입력 상태에 대한 전환이며 게임 전체 보유 패 동기화는 아닙니다.
